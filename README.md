# Outlook-Organisation Druckvorstufe

**Postfach:** vorstufe@horizonte.ch (Outlook für Mac, neues Outlook)

**Ziel:** Postfach übersichtlich filtern. Schluss mit dem Kategorien-Chaos.

---

## Kurzfassung

- Jede Mail bekommt **einen Namen** und **einen Status**.
- Es gibt **nur die Kategorien unten**. Keine neuen anlegen.
- **Nie nur "warten"**. Immer mit Grund.
- **Ordner** nur zum **Archivieren**.

---

## Kategorien

### Status (genau einer pro Mail)

| Kategorie | Bedeutung |
|---|---|
| **zu erledigen** | Neu, noch nicht angefangen |
| **in Bearbeitung :)** | Jemand arbeitet daran |
| **GzD erstellen** | Gut zum Druck muss erstellt werden |
| **Warten GzD** | GzD ist beim Kunden. Wir warten auf Freigabe. *(alt: GzD warten)* |
| **Warten Kunde** | Wir warten auf Daten oder Antwort vom Kunden. *(alt: warten)* |
| **Warten LT** | Wir warten auf die **Lauftasche**. *(neu)* |
| **Info** | Nur zur Kenntnis, keine Aufgabe |

**GzD** = **Gut zum Druck**

### Personen (genau eine pro Mail)

- **Florian Stauber**
- **Simone Ruppli**
- **Thomas Heuberger**

### Extra

- **Priorität** – für eilige Aufträge. Es gibt **kein "dringend"**.

---

## Regeln

1. **Name und Status sind getrennt.** Pro Mail: 1 Name + 1 Status.
2. **Nie nur "warten".** Immer: Warten GzD, Warten Kunde oder Warten LT.
3. **Keine neuen Kategorien.** Fehlt etwas? Im Team besprechen.
4. **Ordner nur zum Archivieren.** Arbeit läuft über Kategorien.
5. **Status wechselt?** Alte Status-Kategorie entfernen, neue setzen.

---

## Alte Kategorien umstellen

| Alt | Neu |
|---|---|
| GzD warten | **Warten GzD** |
| warten | **Warten Kunde** |
| dringend | **Priorität** |

Danach die alten Kategorien **löschen**.
